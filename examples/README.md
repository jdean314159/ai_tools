# Examples

Worked applications built with the `ai_tools` packages.

| Example | Status | Notes |
|---|---|---|
| `language_tutor` | reference example | Spaced-repetition tutor composing `llm_engines` and `engram`. |
| `agent_coordination_teaching` | teaching example | `agent_lib` coordination and multi-agent workflow demonstrations. |
| `diagnostics_agent` | completed campaign | Read-only local-LLM system diagnostics; process docs live under `docs/projects/diagnostics_agent/`. |
| `mail_assistant` | completed case study | Retained local-first Thunderbird reader and reviewed IMAP-mutation example; adoption is closed and it is not an active product direction. |
| `asc_probe` | evaluation probe | Reproducible agent-steering and coordination probe assets. |
