# Historical documents

This directory contains retained historical or transition-era documents that are no longer part of the active architecture/documentation path.

Current sources of truth live in the active repo documentation path:

- `docs/design/VISION.md`
- `docs/internal/STATUS.md`
- `docs/internal/ROADMAP.md`
- `ADR_INDEX.md`

Package-specific active docs should live in each package `README.md`.

The package legacy READMEs kept for reference should also live here rather than beside the active package README files.
